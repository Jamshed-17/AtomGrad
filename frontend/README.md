# АтомГрад - Веб-приложение

Веб-приложение для отображения информации о персонах атомных городов.

## Технологический стек

- **React 19** - UI библиотека
- **TypeScript** - типизация
- **Vite** - сборщик и dev-сервер
- **Material-UI (MUI)** - компоненты UI
- **React Router** - маршрутизация
- **Axios** - HTTP-клиент
- **React Hook Form** - управление формами

## Структура проекта

```
src/
├── api/              # API-клиент и методы
│   ├── client.ts     # Настройка Axios с базовым URL
│   ├── auth.ts       # API методы аутентификации
│   └── persons.ts    # API методы для работы с персонами
├── components/       # Переиспользуемые компоненты
│   ├── Header.tsx    # Шапка сайта
│   └── ProtectedRoute.tsx  # Защищенный роут
├── contexts/         # React контексты
│   └── AuthContext.tsx  # Контекст аутентификации
├── pages/            # Страницы приложения
│   ├── HomePage.tsx  # Главная страница со списком персон
│   ├── PersonDetailPage.tsx  # Детальная страница персоны
│   ├── LoginPage.tsx  # Страница входа
│   └── AdminPersonsPage.tsx  # Админка: создание/редактирование
├── theme/            # Тема MUI
│   └── theme.ts      # Настройка цветов и стилей
└── App.tsx           # Главный компонент с роутингом
```

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите dev-сервер:
```bash
npm run dev
```

3. Откройте браузер по адресу `http://localhost:5173`

## Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`.

## API

Базовый URL по умолчанию: `https://atomgrad.site`

Для разработки можно изменить URL API, создав файл `.env` в корне проекта:

```env
VITE_API_URL=http://atomgrad.site:8000
```

Или для продакшена:
```env
VITE_API_URL=https://atomgrad.site
```

Все запросы используют HTTP-only Cookie для аутентификации.

### Решение проблем с загрузкой данных

Если видите ошибку при загрузке персон:

1. **Проверьте URL API** - откройте консоль браузера (F12) и посмотрите на ошибки
2. **CORS ошибка** - убедитесь, что бэкенд настроен для работы с вашим доменом
3. **Сетевая ошибка** - проверьте, что API сервер запущен и доступен
4. **Неправильный URL** - создайте `.env` файл с правильным `VITE_API_URL`

После изменения `.env` файла перезапустите dev-сервер.
