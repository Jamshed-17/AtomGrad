# АтомГрад - Frontend

Frontend часть веб-приложения для отображения информации о деятелях атомных городов.

## 🛠️ Технологический стек

- **React 19** — UI библиотека
- **TypeScript** — строгая типизация
- **Vite 7** — сборщик и dev-сервер
- **Material-UI (MUI) v7** — компоненты UI
- **React Router v7** — маршрутизация
- **Axios** — HTTP-клиент
- **React Hook Form** — управление формами
- **Nginx** — веб-сервер для продакшена

## 🚀 Установка и запуск

### Предварительные требования

- **Node.js 20+**
- **npm** или **yarn**

### Локальная разработка

1. **Установите зависимости:**
```bash
npm install
```

2. **Создайте файл `.env` в корне `frontend/`:**
```env
VITE_API_URL=http://localhost:8000
```

Для продакшена используйте:
```env
VITE_API_URL=/api
```

3. **Запустите dev-сервер:**
```bash
npm run dev
```

4. **Откройте браузер:** http://localhost:5173

### Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`. Эти файлы автоматически используются в Docker контейнере с Nginx.

### Предпросмотр продакшен сборки

```bash
npm run preview
```

## 🔌 API Интеграция

### Настройка API URL

Базовый URL API настраивается через переменную окружения `VITE_API_URL`:

**Для разработки:**
```env
VITE_API_URL=http://localhost:8000
```

**Для продакшена (через Nginx proxy):**
```env
VITE_API_URL=/api
```

### Структура API клиента

Все API запросы проходят через настроенный Axios клиент (`src/api/client.ts`), который:
- Автоматически добавляет базовый URL
- Обрабатывает ошибки 401/403 (редирект на `/login`)
- Настраивает credentials для работы с cookies

### API методы

**Аутентификация** (`src/api/auth.ts`):
- `login(login: string, password: string)` — вход в систему
- `logout()` — выход из системы

**Деятели** (`src/api/persons.ts`):
- `getAll()` — получить всех деятелей
- `getById(id: number)` — получить деятеля по ID
- `getByName(name: string)` — получить деятеля по имени
- `create(data: PersonCreate)` — создать деятеля (требует auth)
- `update(id: number, data: PersonCreate)` — обновить деятеля (требует auth)
- `delete(id: number)` — удалить деятеля (требует auth)

**Администраторы** (`src/api/admins.ts`):
- `getAll()` — получить всех админов (требует superadmin)
- `create(data: AdminCreate)` — создать админа (требует superadmin)
- `delete(id: number)` — удалить админа (требует superadmin)

## 🛣️ Маршрутизация

Приложение использует React Router v7 со следующими маршрутами:

| Путь | Компонент | Доступ |
|------|-----------|--------|
| `/` | `HomePage` | Публичный |
| `/persons/:id` | `PersonDetailPage` | Публичный |
| `/login` | `LoginPage` | Публичный |
| `/admin/persons/new` | `AdminPersonsPage` | Требует auth |
| `/admin/persons/:id` | `AdminPersonsPage` | Требует auth |
| `/admin/persons/delete` | `AdminDeletePersonPage` | Требует auth |
| `/admin/admins` | `AdminManagementPage` | Требует superadmin |

Защищенные роуты обернуты в компонент `ProtectedRoute`, который проверяет аутентификацию.

## 🐛 Решение проблем

### Проблемы с загрузкой данных

1. **Проверьте URL API:**
   - Откройте консоль браузера (F12)
   - Проверьте Network tab на наличие ошибок
   - Убедитесь, что `VITE_API_URL` правильно настроен

2. **CORS ошибка:**
   - Убедитесь, что бэкенд настроен для работы с вашим доменом
   - Проверьте `FRONTEND_ORIGINS` в настройках бэкенда

3. **Сетевая ошибка:**
   - Проверьте, что API сервер запущен и доступен
   - Проверьте URL в `.env` файле

4. **После изменения `.env`:**
   - Перезапустите dev-сервер (`npm run dev`)

### Проблемы с аутентификацией

1. **Не сохраняется сессия:**
   - Проверьте, что cookies разрешены в браузере
   - Убедитесь, что `credentials: 'include'` установлен в Axios

2. **Автоматический редирект на `/login`:**
   - Это нормальное поведение при истечении токена
   - Войдите заново в систему

### Проблемы со сборкой

1. **Ошибки TypeScript:**
   ```bash
   npm run build
   ```
   Проверьте ошибки в консоли и исправьте типы

2. **Ошибки линтера:**
   ```bash
   npm run lint
   ```

1. Создайте компонент в `src/pages/`
2. Добавьте маршрут в `src/App.tsx`
3. При необходимости добавьте защиту через `ProtectedRoute`

1. Определите тип данных в соответствующем файле API
2. Добавьте метод в `src/api/[resource].ts`
3. Используйте метод в компонентах
